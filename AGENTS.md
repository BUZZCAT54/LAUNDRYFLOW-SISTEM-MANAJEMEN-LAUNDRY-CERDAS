# Git workflow

- Pull the current branch from its GitHub upstream before starting each new task.
- Preserve existing local changes. If a pull is blocked by unrelated changes or conflicts, resolve it without discarding work; ask only when intent is unclear.
- After completing and checking the requested changes, commit the task's files and push to the current branch's GitHub upstream.
- Keep unrelated local changes out of the task commit. Do not force-push.
- Verify the push succeeded and report the commit and any remaining limitations.
