# Prototype interaktif Owner & Kasir

[Mainkan prototype](https://www.figma.com/proto/2xUPWBPsLs8uAMTemGNKI8?node-id=10-177&starting-point-node-id=10%3A177)

[File desain yang dapat diedit](https://www.figma.com/design/2xUPWBPsLs8uAMTemGNKI8)

Pilih Owner atau Kasir pada layar awal. Prototype memakai data contoh dan form yang sudah diisi untuk mendemonstrasikan alur utama.

- Kasir: login, dashboard, transaksi tunai/QRIS/transfer, konfirmasi, nota, filter status pesanan, detail pesanan, pelanggan, dan laporan.
- Owner: login, dashboard, pelanggan, riwayat nota, pengeluaran, laporan, dan analitik.
- Tombol cetak/download memperlihatkan dialog simulasi. Tidak ada autentikasi, pembayaran nyata, atau sinkronisasi server.
- Menu manajemen di luar alur utama belum dihubungkan.

## Status sinkronisasi — 14 Oktober 2026

Website sudah menghapus diskon checkout dan alamat pelanggan Kasir, serta metode pembayaran pengeluaran Owner. Perubahan terakhir ini **belum diterapkan di Figma** karena batas pemakaian Figma MCP paket Starter tercapai. Layar terkait: empat keadaan transaksi Kasir, detail/edit pelanggan Kasir, serta kedua keadaan pengeluaran Owner.

Interaksi navigasi dan overlay sudah tersimpan di Figma. Pemeriksaan visual dilakukan melalui gambar frame; uji klik menyeluruh di pemutar browser belum selesai karena pemutar masih memuat.
