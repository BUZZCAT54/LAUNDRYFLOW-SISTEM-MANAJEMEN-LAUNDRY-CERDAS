# User flow Syaqil Laundry

Buka `syaqil-laundry-user-flow.drawio` melalui **app.diagrams.net → File → Open From → Device**. Semua simpul, panah, dan teks dapat diedit.

Empat halaman:
1. Akses dan ruang kerja
2. Kasir: transaksi baru, pembayaran langsung, dan bayar nanti
3. Kasir: proses cucian, pelunasan, dan nota
4. Owner: menu manajemen dan keuangan

Biru: proses. Kuning/belah ketupat: keputusan. Hijau: hasil berhasil. Jingga: tagihan/perbaikan input. Abu-abu: catatan.

Flow mengikuti fitur repository pada 16 Oktober 2026. Owner masih prototype frontend; autentikasi dan sinkronisasi Kasir–Owner belum tersedia. Status cucian berbeda dari status pembayaran. Pendapatan Kasir hanya menghitung nota lunas menurut tanggal pesanan.

Diskon, parfum, alamat/loyalty/kategori/status aktif pelanggan, serta metode pembayaran pengeluaran Owner tidak disertakan. Alamat usaha dan status akun karyawan/layanan tetap relevan.
