# Wireframe Syaqil Laundry

Wireframe dipisah menjadi dua paket. Tidak ada papan atau arsip gabungan.

- [Kasir](kasir/README.md): 10 layar untuk transaksi, bayar nanti, pelunasan, pelanggan, nota, dan laporan. [Unduh ZIP](wireframe-kasir.zip).
- [Owner](owner/README.md): 10 layar untuk dashboard, pelanggan, nota, manajemen, keuangan, dan pengaturan. [Unduh ZIP](wireframe-owner.zip).

Masing-masing folder berisi SVG per layar, papan SVG, dan pratinjau PNG. Label dan tombol demo sudah dihapus.

Wireframe belum ditulis langsung ke Figma karena kuota konektor Starter habis. Impor masing-masing paket ke halaman Figma terpisah: `Wireframe — Kasir` dan `Wireframe — Owner`.
