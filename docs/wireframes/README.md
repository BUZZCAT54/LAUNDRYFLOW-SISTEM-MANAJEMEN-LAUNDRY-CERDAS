# Wireframe Syaqil Laundry

20 layar desktop 1200 × 800: 10 Kasir dan 10 Owner. Gaya grayscale mengikuti referensi, dengan struktur aplikasi web.

## Masukkan ke Figma

1. Buka file Design di Figma.
2. Buat halaman `Wireframe — Owner & Kasir`.
3. Seret `wireframe-overview.svg` untuk seluruh papan, atau SVG per layar untuk ukuran aslinya.
4. SVG berisi teks dan bentuk vektor terpisah, bukan screenshot. Hasil konversi teks mengikuti importer Figma.
5. Gunakan frame dan hubungkan tombol di tab Prototype jika membutuhkan simulasi klik. Paket ini belum memiliki interaksi Figma.

## Perubahan terbaru

- Kasir: tidak ada diskon, parfum, alamat pelanggan, loyalty, kategori pelanggan, atau status aktif pelanggan.
- Bayar nanti menampilkan Belum bayar, sisa tagihan, dan pelunasan pada nota yang sama. Status cucian tetap terpisah.
- Owner: pengeluaran tanpa metode pembayaran. Data pelanggan disederhanakan. Status akun karyawan tetap ada.
- Alamat pada pengaturan adalah alamat usaha untuk nota, bukan alamat pelanggan.
- Banner dipertahankan sebagai placeholder; dekorasi promosi tambahan dihilangkan.
