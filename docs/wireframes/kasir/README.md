# Wireframe Kasir — Syaqil Laundry

10 layar desktop 1200 × 800, khusus Kasir.

## Impor ke Figma

1. Buat halaman `Wireframe — Kasir` di file Design.
2. Seret `wireframe-kasir.svg` untuk seluruh papan, atau SVG per layar untuk ukuran aslinya.
3. SVG berisi bentuk dan teks vektor, bukan screenshot. Konversi teks mengikuti importer Figma.

Belum memiliki interaksi Prototype. Belum ditulis langsung ke Figma karena kuota konektor Starter habis.
